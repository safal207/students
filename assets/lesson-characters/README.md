# Команда уроков AI PATH

Мира — взрослая ученица, Данил — человек-ментор, Пикс — бот-помощник. Это вымышленные рисованные персонажи, а не фотографии преподавателей или отзывы учеников.

Шесть сцен созданы инструментом imagegen в едином стиле AI PATH: начало, размышление, проверка, исправление, сравнение и завершение. Лица и одежда сохраняются между сценами. Точные описания и дата генерации — в [prompts.json](prompts.json).

В ноутбуках изображения встроены как JPEG-вложения, поэтому для их просмотра не требуется внешний хостинг. Обложка — 960×640, реакции — 480×320. Из исходных PNG выполнены только уменьшение и преобразование формата; числа, результаты вычислений и графики не нарисованы генератором изображений.
