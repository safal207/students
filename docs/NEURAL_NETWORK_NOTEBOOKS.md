## Как продолжить

1. Пройди короткий урок и его небольшой эксперимент.
2. Открой полную исходную работу и сравни её цель, данные и архитектуру с вводным примером.
3. Для воспроизведения большой работы подготовь отдельное окружение и доступный набор данных по её источникам.
4. Отделяй измеренный результат своего запуска от исторического вывода автора.

Проверки коротких уроков запускает [текущий workflow](../.github/workflows/notebook-audit.yml). Отчёт о выполнении подтверждает только соответствующий код и коммит; архивные исследования требуют отдельного воспроизведения. Исторические медицинские материалы предназначены для учебного разбора, а не для диагностики.

**Источники:** [safal207/students](https://github.com/safal207/students), архивные ссылки в таблицах и авторские ссылки внутри каждого ноутбука. Условия использования сторонних данных, изображений и кода сохраняются у исходных материалов.
